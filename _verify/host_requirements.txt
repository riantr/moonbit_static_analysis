# THE HOST CONTRACT OF THE SHIPPED ARTIFACT.
#
# WHAT THIS FILE IS. The published wasm is not self-contained: it imports 90
# symbols from `moonbitlang/async`, and the HOST has to provide every one of
# them when the module is instantiated. `moonx` provides them from the async
# package BUNDLED WITH THE USER'S MOONBIT TOOLCHAIN -- not from the version
# this package pins in `moon.mod`. So the artifact's host requirements are a
# property of the PUBLISHED BYTES, and nothing in the source tree can see them.
#
# WHY IT IS PINNED. On 2026-10-30 the `moonbitlang/async` 0.22.5 -> 0.22.6 bump
# added three host-required symbols to the published wasm:
#
#     moonbitlang/async thread_pool/make_write_console_job
#     moonbitlang/async thread_pool/make_read_console_job
#     moonbitlang/async thread_pool/get_read_console_result
#
# async 0.22.6 declares those three as externs the HOST must supply; 0.22.4
# and 0.22.5 do not declare them at all. A user whose toolchain bundled
# 0.22.5 therefore got, from 0.4.38:
#
#     LinkError: WebAssembly.Instance(): Import #5 "moonbitlang/async"
#     "thread_pool/make_write_console_job": function import requires a callable
#
# The 104-import surface of 0.4.37 links on such a toolchain; the 107-import
# surface of 0.4.38 does not. No test caught it, because every gate here runs
# the analyzer from SOURCE -- the published BYTES were never linked against a
# host.
#
# THE RULE. This file IS the contract: the gate compares the artifact's
# `moonbitlang/async` imports against it, EXACTLY, in both directions. A
# dependency bump that widens the artifact's host requirements must edit this
# file -- and the edit is a decision: it raises the minimum MoonBit toolchain
# a user needs, and that has to be written down in the README and the
# CHANGELOG. A bump that does NOT edit this file fails the gate instead of
# silently dropping users.
#
# `min-host-async` is the newest async whose extern set covers every symbol
# below. 0.22.4 and 0.22.5 both declare 223 externs and both cover all 90.
# It must equal the `moonbitlang/async` pin in `moon.mod`: the floor and the
# pin are one fact, and two facts that can disagree will.
